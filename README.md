# BrowserCraft for macOS

BrowserCraft 是基于 Flow Browser v0.12.0 的桌面浏览器。本仓库分发 macOS Apple Silicon 版本。

从 [Releases](https://github.com/gfushilu07-arch/browsercraft/releases) 下载 DMG 安装浏览器。已配置此发布渠道的版本可以在 Settings → About 中检查更新。

每个版本的 Release 都附上与该版本对应的源码、构建脚本和 GPLv3 许可证。下载文件名中带有 `corresponding-source` 的压缩包，在其中的 BUILDING.md 查看本机构建步骤。

上游项目为 [Flow Browser](https://github.com/MultiboxLabs/flow-browser)。
